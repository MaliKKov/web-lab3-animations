# Лабораторная работа №3 — CSS-анимации

**Дисциплина:** WEB-программирование

**Тема:** «Работа с 2D и 3D анимацией и трансформацией»

## Описание проекта

Проект представляет собой набор из четырёх анимированных композиций, созданных средствами HTML5 и CSS3 без использования JavaScript.

Цель работы — изучение CSS-анимаций, трансформаций, переходов и закрепление навыков вёрстки веб-страниц.

## Реализованные анимации

**Анимация №1 — Котик (`cat.html`)**

Мордочка котика, который периодически моргает, смотрит по сторонам и изменяет форму рта.

**Анимация №2 — Свечи (`candles.html`)**

Две свечи: высокая свеча сдувает пламя короткой, после чего короткая свеча краснеет и вновь зажигается.

**Анимация №3 — Конверт (`envelope.html`)**

При наведении курсора красный конверт открывается, а из него плавно появляется письмо.

**Анимация №17 — Снежный шар (`snowglobe.html`)**

Зимняя композиция с домиком, деревьями и непрерывно движущимися снежинками внутри стеклянной сферы.

## Использованные технологии

- HTML5 — структура веб-страниц.
- CSS3 — оформление элементов.
- `@keyframes` — создание анимаций.
- `animation` — управление воспроизведением.
- `transform` — перемещение, вращение и масштабирование.
- `transition` — плавные переходы.
- `opacity` — изменение прозрачности.
- `clip-path` и `border-radius` — создание фигур.
- Media Queries — адаптация интерфейса.

## Как запустить

1. Скачать репозиторий через **Code → Download ZIP**.
2. Распаковать архив.
3. Открыть файл `index.html` в браузере.
4. Выбрать необходимую анимацию на главной странице.

Для запуска не требуется установка дополнительных программ или подключение к серверу.
